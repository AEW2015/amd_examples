# AXI4 HyperRAM Interface Prototype

This repository contains a prototype AXI4 HyperRAM interface designed for the Spartan UltraScale+ SCU35 development board.

## Overview

- **Purpose:** Demonstrate interfacing HyperRAM memory with an AXI4 bus on the SCU35 platform.
- **Platform:** AMD Spartan UltraScale+ SCU35 Dev Board
- **Status:** Prototype (for evaluation and development use)

## Features

- AXI4-compliant memory interface
- Example HDL and constraints for SCU35
- Basic testbench included

## Disclaimer

This project is a prototype and may require further development for production use.
